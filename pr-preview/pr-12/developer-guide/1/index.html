Red Hat Open Training Contributor Guide

Introduction

This guide is the reference for anyone developing or contributing training content through the Red Hat Open Training program (Quick Courses built with AsciiDoc and Antora).

Open Training helps subject matter experts share knowledge across Red Hat and beyond. Program overview and intake live on the PERT Confluence space: Open Training Program.

A key goal is to enable "citizen developers" and reduce the time required to build and maintain training content. Creating content across many products and fast release cycles takes more than one team — this guide and the course starter template help you focus on the technical story while the framework handles structure and publishing.

Start here

  1. New to Open Training? Follow Getting started.

  2. Create a content repository from the course-starter-template (see that repo README for course-init.sh).

  3. Need a lab environment? See the Lab Infrastructure Guide.

  4. Formatting and AsciiDoc help: AsciiDoc quick reference and related pages under References.
